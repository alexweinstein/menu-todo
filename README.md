# Menu Todo for your phone

The phone version of Menu Todo, a menu bar to-do list for the Mac. It edits the same `tasks.json` in your Dropbox as the Mac app, so both stay in sync.

Your tasks are never stored here. The page talks straight from your browser to your own Dropbox after you sign in.

Open it at <https://alexweinstein.github.io/menu-todo/>, then in Safari choose Share › **Add to Home Screen**.

This folder is generated by `web/deploy.sh` in the Menu Todo project, so edit the files there instead.
